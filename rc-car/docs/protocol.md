# 인터페이스 명세 v1 (라즈베리파이 ↔ 아두이노)

- 버전: **v1** (2026-11-20 확정, 박노현 · 정민재)
- 이 문서는 두 사람의 코드가 만나는 지점의 약속이다. 바꿀 때는 맨 아래 **변경 절차**를 따른다.
- 관련 문서: 핀 배치는 `docs/design.md`, 학습 데이터 형식은 `docs/data_format.md`
- 기준: 수업 실습 10(motor_lab) · 11(cv_lab)의 인터페이스 + 설계서 추가 기능(초음파, LCD, 가변저항)

## 1. 값의 의미 (부호 · 단위)

| 값 | 범위 | 뜻 |
| --- | --- | --- |
| 조향 `steer` | −1.0 ~ +1.0 | 음수 = 왼쪽, 0 = 직진, 양수 = 오른쪽 |
| 속도 `speed` | 0.0 ~ 1.0 | 기본 0.35 |
| 바퀴 값 | −1.0 ~ +1.0 | 음수 = 후진 |
| 시리얼 명령 숫자 | −255 ~ 255 (정수) | 바퀴 값 × 255 를 반올림 |
| 거리 | mm (정수) | |
| 시간 | 파이: 초(float) · 아두이노: ms(`millis()`) | |

## 2. 통신 규칙

### 공통
- USB 시리얼 (파이에서 `/dev/ttyACM0`), **115200 bps**
- ASCII 대문자, **한 줄 = 한 명령**, 줄 끝 `\n` (`\r`은 무시)
- 한 줄 최대 **31글자** (아두이노 버퍼 32칸)
- 형식이 틀린 줄은 **통째로 무시** (`sscanf`가 숫자를 필요한 개수만큼 꺼냈을 때만 실행)
- 숫자는 10진 정수만 (`94.5`, `0x10` → 무시). 범위 밖 값은 ±255로 자름

### 파이 → 아두이노

| 명령 | 뜻 | 예 |
| --- | --- | --- |
| `M,<좌>,<우>` | 바퀴 세기 −255 ~ 255 (음수 = 후진, 0 = 정지) | `M,94,78` |
| `S` | 즉시 정지 | `S` |
| `PING` | 연결 확인 → `PONG` 응답 | `PING` |
| `MODE,<CV\|CNN>` | LCD에 주행 모드 표시 | `MODE,CNN` |
| `D,<좌>,<우>` | (시험용) 모터는 돌리지 않고 계산한 PWM만 회신 | `D,94,78` |

- 파이는 매 프레임(약 20 Hz) `M`을 보내되 **간격이 0.1초를 넘지 않게** 한다 (하트비트).
- 프로그램 종료(정상 · Ctrl+C) 시 반드시 `S`를 보낸다.

### 아두이노 → 파이

| 메시지 | 언제 | 예 |
| --- | --- | --- |
| `READY` | 부팅 직후 한 번 | `READY` |
| `PONG` | `PING`을 받았을 때 | `PONG` |
| `D <방향> <PWM> <방향> <PWM>` | `D` 명령의 응답 (방향 F 전진 · B 후진 · S 정지) | `D F 169 F 160` |
| `R,<mm>` | 전방 거리, 200 ms마다 | `R,230` |
| `O,1` / `O,0` | 장애물 정지 시작 / 해제 | `O,1` |

- 아두이노 → 파이 메시지는 디버깅 · 기록용이다. 파이는 읽지 않아도 동작해야 한다.
- 파이에서 응답을 읽기 전에는 `ser.reset_input_buffer()`로 쌓인 메시지를 버린다.

## 3. 아두이노 동작 규칙

### 정지 우선순위
1. 장애물 정지 중 → 정지 (파이 명령 무시)
2. 마지막 `M` 명령 후 **500 ms** 경과 → 정지
3. 그 외 → 받은 명령 실행

### PWM 변환
- 명령 **0 → PWM 0** (반드시 `map`보다 먼저 처리)
- 명령 1 ~ 255 → PWM `MIN_PWM` ~ `maxPwm`
- `maxPwm = map(analogRead(A2), 0, 1023, MIN_PWM, 255)` — 가변저항으로 현장에서 최고 속도 조절
- 좌우 보정이 필요하면 `LEFT_BOOST` / `RIGHT_BOOST`를 전진 PWM에 더함 (최대 255)
- L293D 구동: EN 핀 = PWM 세기, IN 핀 = 방향
  - 전진 IN1=HIGH, IN2=LOW · 후진 IN1=LOW, IN2=HIGH · 정지 EN=0
  - 바퀴가 반대로 돌면 배선 대신 코드의 `LEFT_DIR` / `RIGHT_DIR`을 뒤집는다

### 장애물 판단 (HC-SR04)
- 60 ms마다 측정, `pulseIn` timeout 25000 µs, 응답 없음(0) = 장애물 없음
- **200 mm 미만 3회 연속 → 정지**, **250 mm 초과 3회 연속 → 재출발** (경계에서 멈췄다 섰다 반복 방지)

### LCD (16×2, SoftwareSerial 9600)
- 500 ms마다, 바뀐 내용만 보낸다 (전송 중 인터럽트가 꺼져 시리얼 명령이 깨질 수 있음)
- 1행: `CNN RUN  230mm` — 모드(CV/CNN), 상태(RUN/STOP/OBST), 거리
- 2행: `PWM 180/200 M255` — 좌/우 PWM, maxPwm

### 기타
- `delay()` 사용 금지, `millis()`로 작업 주기 관리

## 4. 파이 쪽 계산 규칙

- 바퀴 값 (`mix`): 왼쪽 = 속도 × (1 + 조향), 오른쪽 = 속도 × (1 − 조향).
  절댓값이 큰 쪽이 1을 넘으면 두 값을 그 값으로 나눠 **비율을 유지**하며 줄인다.
- 커브 감속: `speed × (1 − 0.4 × |steer|)`
- 명령 변환 (`to_command`): −1 ~ 1로 자르기 → × 255 → 반올림 → `"M,<좌>,<우>\n"`
- 선을 놓침: 하던 조향 유지, **6프레임 연속**이면 `M,0,0`
- 카메라 320×240 BGR, CNN 입력은 `common/preprocess.py` (66×200, YUV, 0~1)

| BAUD | 115200 | ✓ | ✓ |

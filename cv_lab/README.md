# cv_lab — OpenCV 선 따라가기 (베리파이)

강의 11. cv_lab 기준 완성본. 카메라 · 웹 화면 · 모터 · 주행 반복 · C1~C5가 `cv_lab.py` 하나에 모두 들어 있다.
아두이노에는 강의의 `motor_serial.ino` (또는 `motor_lab.ino`)가 올라가 있어야 한다.

| 파일 | 내용 |
| --- | --- |
| `cv_lab.py` | 주행 프로그램 (이것만 실행하면 됨) |
| `check_cv.py` | C1~C5 자동 확인 21개 (카메라 · 모터 없이) |
| `check_improve.py` | 선 검출 개선 ①~④ 확인 10개 (카메라 · 모터 없이) |
| `check_safety.py` | 충돌 방지 확인 24개 (가짜 아두이노, 센서 없이) |
| `check_collect.py` | 자동 데이터 수집 확인 9개 (자동 흔들기, 확실할 때만 저장) |
| `motor_serial_berrypi/` | 아두이노 모터 스케치 (L9110S) |
| `motor_safety_berrypi/` | 아두이노 모터 + 충돌 방지 스케치 (초음파, 피에조) — 초안 |
| `test_link.py` | 카메라 + 아두이노 PING/PONG 확인 (모터 안 돎) |
| `test_motor.py` | 바퀴 전진 · 좌회전 · 우회전 · 후진 · 자동 정지 확인 |

## 1. 파이에 받기 (처음 한 번)

```bash
sudo apt install -y python3-opencv python3-numpy python3-flask python3-picamera2 python3-serial python3-venv git
cd ~
git clone https://github.com/metollove2-oss/berrypi.git
cd ~/berrypi/cv_lab
python3 -m venv --system-site-packages venv
```

이미 받았으면 `cd ~/berrypi && git pull` 로 최신 코드만 받는다.

## 2. 매번 실행

```bash
cd ~/berrypi/cv_lab
source venv/bin/activate        # 줄 앞에 (venv) 가 붙으면 OK

python3 check_cv.py             # 통과 21 / 21
python3 test_link.py            # 카메라 OK + PONG
python3 test_motor.py           # 바퀴 띄우고! 5가지 동작 확인
python3 cv_lab.py               # 주행
```

`cv_lab.py`를 켠 채로 PC 브라우저에서 `http://<파이IP>:8000` (파이 IP: `hostname -I`)

| 조작 | 방법 |
| --- | --- |
| 출발 / 정지 | Space 또는 버튼 |
| 녹화 | R (출발 중이고 선을 찾은 프레임만, 초당 10장 → `data/<날짜_시간>_lab/`) |
| 종료 | 터미널에서 Ctrl+C (모터 정지) |
| 안전 | 브라우저를 닫거나 응답이 1초 끊기면 정지, 선을 6프레임 연속 놓치면 정지 |

## 3. 화면 보는 법

- 하늘색 줄: 자르는 위치 (roi_top) · 초록 띠: 선을 찾는 곳 (look) · 빨간 점: 찾은 선
- 주황 화살표: 조향 방향 · 오른쪽 흑백 화면: mask (선만 하얗게 보여야 함)
- 맨 위 글자: `상태 x 오차 조향 명령` — 상태 RUN(주행) / HOLD(잠깐 놓침) / LOST(정지) / STOP

## 4. 트랙에서 슬라이더 조절 (한 번에 하나씩)

| 슬라이더 | 처음 | 이럴 때 |
| --- | --- | --- |
| thresh | 80 | mask에 바닥 얼룩 → ↓, 선이 끊김 → ↑ |
| roi_top | 0.45 | 벽 · 바깥 물건이 mask에 보임 → ↑ |
| look | 0.6 | 커브를 늦게 돎 → ↓, 너무 일찍 안쪽으로 → ↑ |
| kp | 1.0 | 커브에서 바깥으로 나감 → ↑, 직선에서 지그재그 → ↓ |
| kd | 0.5 | 흔들림이 계속 → ↑, 덜컥거림 → ↓ |
| speed | 0.35 | 처음엔 0.25~0.35, 바퀴가 안 돌면 ↑ |

잘 되는 값은 적어 두기 → 텀 프로젝트 `rc-car/pi/config.py`에 사용.

## 5. 선 검출 개선 ① ~ ④ (다른 물체를 선으로 잡을 때)

웹 화면 버튼 아래 체크박스로 하나씩 켜고 끄며 비교할 수 있다 (기본: 모두 켬).

| 개선 | 하는 일 | 관련 슬라이더 |
| --- | --- | --- |
| ① 아래 연결 | 화면 아래쪽(차 바로 앞)까지 이어진 흰 덩어리만 선으로 봄. 떠 있는 물체는 mask에서 회색으로 표시되고 무시됨 | `min_bottom` (0.9 = mask 아래 10% 안까지 와야 함) |
| ② 선 폭 | 띠 안의 흰 구간 중 폭이 3 ~ `max_w` 픽셀인 것만 후보. 넓은 그림자 · 얼룩 제거 | `max_w` (테이프가 굵게 보이면 ↑) |
| ③ 가까운 선 | 후보가 여러 개면 지난 프레임 위치에 가장 가까운 것 선택 | - |
| ④ 점프 무시 | x가 `max_jump` 픽셀 넘게 갑자기 튀면 2프레임까지 무시(HOLD), 3번째부터 인정 | `max_jump` |

화면 보기: 띠 아래 노란 막대 = 후보 구간, 빨간 막대 = 고른 선. 두 번째 글자줄 `line:` 이 이유를 보여 줌
(`ok` 찾음 · `none` 선 없음 · `width` 폭이 안 맞아 버림 · `jump` 점프 무시).

| 증상 | 조절 |
| --- | --- |
| 진짜 선이 회색(버림)으로 보임 | `min_bottom` ↓ (카메라가 높아 선 아래 끝이 잘리는 경우) |
| 커브에서 `width` 로 자주 놓침 | `max_w` ↑ (기운 선은 띠 안에서 더 넓게 보임) |
| 급커브에서 `jump` 가 자주 뜸 | `max_jump` ↑ |

시험: `python3 check_improve.py` (합성 사진으로 개선 끔/켬 비교, 통과 10 / 10)

## 6. 충돌 방지 (초음파 + 웹 경고창 + 피에조 경고음) — 초안

아두이노에 `motor_safety_berrypi/motor_safety_berrypi.ino` 를 올린다 (기존 모터 스케치 대신, 모터 기능 포함).

**배선**

| 부품 | 연결 |
| --- | --- |
| HC-SR04 | VCC → 5V, GND → GND, Trig → D7, Echo → D8 |
| 피에조 | D5 → 피에조 → GND (능동형 부저면 스케치의 `ACTIVE_BUZZER = true`) |
| 모터 | 그대로 (D3, D11, D9, D10) |

**동작**

| 구간 | 거리 (기본) | 차 | 웹 화면 | 경고음 |
| --- | --- | --- | --- | --- |
| 안전 | 30 cm 이상 | 평소 주행 | - | - |
| 주의 | 15 ~ 30 cm | 거리에 비례해 감속 (30 cm 100 % → 15 cm 30 %) | 노란 띠 | 띠-리 … (0.8초마다) |
| 위험 | 15 cm 미만 | 정지 (상태 OBST) | 빨간 경고창 (깜빡임) | 사이렌 |
| 비상 | 8 cm 미만 | 아두이노가 직접 정지 | 빨간 경고창 | 높은 음 계속 |
| 센서 오류 | 거리 메시지 1초 끊김 | 정지 | 회색 경고창 | - |

- 구간에서 나올 때는 기준 + 3 cm 를 넘어야 함 (경계에서 깜빡임 방지).
- 위험 구간을 벗어난 상태가 0.5초 이어지면 자동 재출발. `자동 재출발` 을 끄면 Space를 다시 눌러야 출발.
- 경고음은 주행 중 + 충돌 방지 켬 일 때만 울림. 비상 정지 경고음은 항상 울림 (`경고음` 끄면 모두 꺼짐).
- 장애물 정지(OBST) 중에는 녹화하지 않음.
- 웹 체크박스: `충돌 방지` · `경고음` · `자동 재출발`. 슬라이더: `caution_cm` · `danger_cm` · `emerg_cm` (아두이노에도 자동 전달).
- **센서 없이 주행할 때는 `충돌 방지` 를 끈다** (켜 두면 센서 오류로 정지).

**통신 규칙 추가**

| 방향 | 메시지 | 뜻 |
| --- | --- | --- |
| 아두이노 → 파이 | `R,<mm>` | 전방 거리, 100 ms마다 (2000 = 2 m 이상, -1 = 센서 응답 없음) |
| 아두이노 → 파이 | `E,1` / `E,0` | 비상 정지 시작 / 해제 |
| 파이 → 아두이노 | `ARM,<0\|1>` | 경고음 켜기 조건 (주행 중 + 충돌 방지 켬) |
| 파이 → 아두이노 | `MUTE,<0\|1>` | 경고음 끄기 |
| 파이 → 아두이노 | `TH,<주의>,<위험>,<비상>` | 구간 거리 (mm) |

**확인 순서**

1. 아두이노만: 스케치 업로드 → 시리얼 모니터(115200, 새 줄) → `R,…` 이 0.1초마다 나오고 손을 대면 숫자가 줄어드는지.
   `ARM,1` 입력 후 손을 25 cm → 12 cm → 6 cm로 가까이 → 경고음이 바뀌고 6 cm에서 `E,1`.
2. PC/파이에서 `python3 check_safety.py` (가짜 아두이노로 24개 확인).
3. 바퀴 띄우고 `cv_lab.py` → 출발 → 상자를 가까이 대며 감속 · 정지 · 재출발 · 경고창 확인.
4. 트랙 측정(보고서): 속도 0.3 / 0.5에서 상자를 향해 10회씩 → 실제 정지 거리, 오경보 횟수 기록.

## 7. 자동 데이터 수집 (CNN 학습용)

OpenCV 주행을 켜 두고 **R** 만 누르면 차가 혼자 돌며 사진 + 정답 조향을 모은다 (초당 10장, 10분 ≈ 6,000장).
웹 체크박스 두 개로 수집 품질을 높인다.

| 체크박스 | 하는 일 | 기본 |
| --- | --- | --- |
| 자동 흔들기 | 주행 조향에 잡음(±`noise_amp`)을 0.4~0.9초씩 섞어 차가 선에서 살짝 벗어나게 함. 절반은 잡음 0 (스스로 돌아오는 구간). **저장되는 정답은 잡음 없는 OpenCV 조향** → 손으로 복구 장면을 녹화할 필요 없음 | 끔 |
| 확실할 때만 저장 | 선 후보가 1개 · 점프 직후 아님 · 놓침 없음인 프레임만 저장 → 틀린 정답 정리가 거의 필요 없음 | 켬 |

- 화면: 주황 화살표 = 실제 조향(잡음 포함), 흰 화살표 = 저장되는 정답. 상태줄에 `흔들기 +0.21`, `건너뜀 N`.
- 감속 중(충돌 방지 주의 구간)에는 흔들지 않음. `noise_amp` 는 0.2~0.4 권장 (크면 선을 놓침).
- 녹화 폴더 `info.json` 에 개선 · 충돌 방지 · 수집 설정이 함께 기록된다.

**15~20분 수집 순서**: 자동 흔들기 + 확실할 때만 저장 켜기 → R → 시계 방향 5분 → (Space로 멈추고 차 방향 바꿔) 반시계 방향 5분
→ 조명을 바꿔 5분 → R로 녹화 끝. 차가 선을 완전히 놓치면 다시 올려 두기만 하면 된다.

시험: `python3 check_collect.py` (가짜 아두이노, 통과 9 / 9)

## 8. 안 될 때

| 증상 | 확인 |
| --- | --- |
| `[모터] 아두이노를 찾을 수 없음` | USB 연결 (`ls /dev/ttyACM*`), PC 시리얼 모니터 · test_motor.py 끄기 |
| `Permission denied: /dev/ttyACM0` | `sudo usermod -aG dialout $USER` → 로그아웃 후 다시 로그인 |
| 카메라 `Device or resource busy` | 카메라 쓰는 다른 프로그램(rpicam-hello, 다른 cv_lab.py) 끄기 |
| `ModuleNotFoundError` | `source venv/bin/activate` 했는지, venv를 `--system-site-packages`로 만들었는지 |
| 선이 오른쪽인데 왼쪽으로 꺾음 | `cv_lab.py` 위쪽 `ROTATE_180 = True` |
| mask가 전부 흰색 / 검은색 | thresh 조절, 조명 |
| 화살표는 맞는데 바퀴가 안 돎 | 배터리, speed, 스케치의 MIN_PWM |
